## 紅葉の下で、何を信じるか

晩秋の山道を抜け、成瀬律と橘栞は温泉宿「栞葉荘」を訪れる。春の取材で知り合った二人は、まだ恋人ではない。栞の亡き母が残した標本帳を受け取るための旅は、紅葉を眺め、言葉を交わす穏やかな時間になるはずだった。

けれど、豪雨と土砂崩れが帰り道を断ち、宿に取り残されたのは七人。停電の後、思いがけない事件が起こる。残された紙、写真に写ったもの、少しずつ食い違う証言。律と栞は、確かめられる事実を手掛かりに、閉ざされた夜を進んでいく。

疑うことと、誰かを大切に思うこと。記録に残る事実と、記録だけでは伝えきれない心。紅葉の温泉宿を舞台に、ミステリーと恋、言えなかった言葉が重なり合う物語。

## この物語の余韻

残したいのは、綺麗な思い出だけじゃない。言いそびれた言葉も、消せない傷も、その先へ届く声のために。紅葉の底で、君の名を呼ぶ。
